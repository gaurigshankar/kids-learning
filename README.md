# Math for Kids

Small, single-file HTML apps for learning math on an iPad. No build step, no dependencies.

- `number-rods.html`: drag number rods (1-10) to add, plus a quiz mode.
- `place-value-blocks.html`: base-ten blocks with trading (10 ones = 1 ten), Build it and Read it challenges.
- `missing-number-rods.html`: Cuisenaire-style workspace for balance problems like 5 + 4 = ? + 3. Build with rods, then pick the missing number.
- `equal-groups.html` ("Share the Cookies"): kindergarten exercise. Give every animal friend the same number of cookies by tapping or dragging. Spoken prompts and counting, picture-only hints (tap Bobo the bear), 4 levels from 2 friends up to finding every way. Hold the home button (1.5 s) to leave.
- `index.html`: simple home page linking to all four.

## Run locally

Open any `.html` file in a browser, or run `python3 -m http.server` in this folder.

## Put it on the iPad

Turn on GitHub Pages (Settings > Pages > Deploy from branch > `main` / root), open the Pages link in Safari, then Share > Add to Home Screen.

## Contributing

Agents and contributors: read `AGENTS.md`, then `DESIGN.md` (mandatory standard for kindergarten exercises) before adding or changing an exercise.
